# M5：總經、國際市場、熱力圖與題材後台

> 狀態（2026-10-21）：T1–T8 已完成（分支 `m5`，從 `m4` 開）。使用者核可計畫後依建議實作；偏離與取捨記在 `docs/DECISIONS.md` D-104～D-112（類股指數不抓、央行／主計總處／PMI 列範圍外、事件用 Fed 2026 種子資料、警示拆成兩種）。加權與櫃買指數的歷史等籌碼回填結束再跑 `make etl-markets-history series=TAIEX,TPEX`。

## 方向

- 不用 FinMind：財報回填正在用每小時額度，M5 的資料都有官方或免金鑰的來源。
- 台股指數用證交所、櫃買中心；國際市場主來源 Yahoo 圖表 API（自寫 adapter，不裝 `yfinance` 套件），備援 FRED；總經用國發會、FRED，其餘官方來源實測後才接。
- 國際市場依交易所當地日期儲存（規則 2）；歷史從 2004 年起，和日線同一個區間。
- 熱力圖只用收盤資料（全市場盤中報價不在範圍內），方塊大小＝收盤價 × `stocks.issued_shares`。

## 任務

### T1 Schema
- `market_series`（代碼、名稱、類別：台股指數／國際指數／匯率／利率／商品／波動率／總經，單位、頻率、時區、主來源與備援的代碼）與 `market_series_values`（序列、日期、開高低收或單一數值）。總經修正值直接覆蓋，原始檔在 RawStore 可追溯。
- `market_series_coverage`（每個序列最後一筆、最後抓取時間）、`market_series_quarantine`。
- `themes`、`stock_themes`（多對多，`valid_from`／`valid_to`）。
- `macro_events`（央行理監事會、FOMC、景氣燈號發布日；可手動編輯）。
- `alerts.kind` 加 `macro_event`；`job_requests` 加 `sync_markets`、`sync_macro`。

### T2 Provider
`twse` 加指數 `fetch_*`／`parse_*`、`tpex` 加櫃買指數，新增 `yahoo`、`fred`、`ndc`。都經 `ProviderRouter` 存原始回應；國際序列主來源 Yahoo、備援 FRED（同一序列兩來源只存主來源，備援只在主來源失敗時用）。

### T3 任務
- `sync_markets`：台股指數（當天）、國際序列（近 10 天補缺）；`backfill_markets` 從 2004 起、可續跑。
- `sync_macro`：國發會、FRED 月資料，有新月份才寫入，順便更新 `macro_events` 中可推算的發布日。
- 品質檢查：開高低收一致、正值、單日漲跌超過門檻（依類別設，VIX 與原油放寬）進隔離區。

### T4 計算與警示
- 熱力圖資料：產業（`stocks.industry`，排除 ETF）與題材在 1／5／20 日的市值加權漲跌幅，漲跌用還原前收；放在 Python 計算或 SQL 檢視表（實作時看效能定）。
- 警示：景氣燈號變色、央行或 Fed 利率變動，寫 `alerts`（`macro_event`）經 `Notifier` 送出。

### T5 `/market` 頁（取代佔位頁）
`page-tabs` 三個分頁：
- 大盤與國際：加權、櫃買、國際序列的最新值與漲跌，每個序列一張小圖（`time-chart`）。
- 熱力圖：產業／題材切換、1／5／20 日切換，方塊＝市值、顏色＝漲跌（`--price-up/down` token，深淺分級）；點產業展開成分股方塊，點個股進個股頁。Treemap 版面自己寫 squarified 純函式並附單元測試，不加依賴。
- 總經：景氣燈號與分數、領先／同時指標、美債殖利率與利差、Fed 利率、事件行事曆。

### T6 首頁與個股頁
首頁「大盤與國際市場」卡（取代佔位）；個股頁顯示所屬產業與題材，連到熱力圖。

### T7 `/admin` 題材編輯與事件行事曆
新增／改名／刪除題材、加減成分股（含起訖日）、編輯 `macro_events`；全部寫 `audit_log`（`theme.*`、`macro_event.*`，在 `audit-log.tsx` 加中文標籤）；另加市場序列隔離區審核。題材預設為空，由使用者自己建。

### T8 `/status`、排程與文件
`/status` 加市場與總經涵蓋列；`etl-daily` 加台股指數與總經檢查；新增 `make etl-markets`（國際序列，平日 07:30 工作排程，美股收盤後）與 `make etl-markets-history`；README、CLAUDE.md、PLAN、DECISIONS。
