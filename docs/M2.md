# M2：持股、費用、配息推算、自選清單

> 狀態（2026-10-19）：T1–T7 已完成（分支 `m2`）。使用者核可範圍並交由實作端決定細節；決策記在 `docs/DECISIONS.md` D-067～D-074。盤中即時層（每 30 秒）已在 M1 完成（D-056），這裡只接上持股。

## 使用者已定的方向

- 成本計算用**平均成本法**（台灣券商常見做法）。
- 除權息**不調整總成本**：現金股利另列收入；配股、分割、減資只改股數（總成本不變，所以每股平均成本會跟著變）。
- 證交稅固定稅率：股票 0.3%、ETF 0.1%；當沖、債券 ETF 等例外另外處理。
- 配息依除息日前一交易日的持有股數推算，標示「估算」。

## 任務

### T1 Schema
- `portfolio_transactions` 加 `day_trade`（當沖，影響稅率）、`fee_rebate`（事後退的預估退佣）、`fee_manual`、`tax_manual`（手動改過的就不再自動重算）。
- `watchlist` 加 `position`（自訂順序）。
- 手續費設定存 `settings`（key `fees`），沒有設定時用預設值。

### T2 Python 計算引擎 `stockhub/engine/portfolio.py`
- 手續費（費率、折扣、最低收費、零股最低收費、當場扣或事後退、捨去或四捨五入）。
- 證交稅率（依類型、日期、當沖）。
- 交易重播：平均成本、已實現損益、配息與股數事件、賣超檢查、今日漲跌、未實現（扣預估賣出成本）。
- 共用測試資料 `testdata/portfolio.json`（`py/scripts/gen_portfolio_fixture.py` 產生）。

### T3 TypeScript 引擎 `web/src/lib/portfolio.ts`
- 逐式對應 T2，用同一份測試資料比對。

### T4 `/admin`：手續費設定與稽核紀錄
- 表單編輯手續費設定（寫入 `audit_log`），顯示試算範例。
- 最近的稽核紀錄列表（M0 預留的讀取函式）。

### T5 `/portfolio`
- 總覽（市值、成本、未實現、已實現、股利、今日漲跌），盤中有報價時用報價。
- 持股表、已出清、交易紀錄（新增、修改、刪除，手續費與稅自動帶入可手動改），配息與股數事件（估算）、已實現明細。
- API 都檢查 session；每次寫入都記稽核紀錄；任何會讓某一天持股變負的修改都拒絕。

### T6 `/watchlist`
- 列表（最新價、漲跌、盤中報價）、欄位排序與自訂順序、備註編輯、加入與移除。

### T7 首頁與文件
- 首頁「持股損益與今日漲跌」接上真資料。
- 更新 `CLAUDE.md`、`docs/PLAN.md`、`docs/DECISIONS.md`。

## M2 續（2026-10-19，使用者要求執行 M2 結束時的六項建議）

### T8 計算引擎擴充（Python 與 TS 同步，重產共用測試資料）
- 當沖獨立結算：同一天勾選當沖的買賣先互相配對，配對的部分單獨算損益，不影響庫存的平均成本；沒配對到的部分照一般買賣處理。
- 股利實收：有輸入實收金額或股數時取代估算值。
- 二代健保補充保費估算（依年度費率與門檻）。
- 預告配息：依目前持股推算未來除權息的應收金額；當天或已過、但正式表還沒匯入的預告事件，暫時當作事件套用。
