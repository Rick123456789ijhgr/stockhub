# M6：新聞、社群情緒、LLM 摘要與警示

> 狀態（2026-10-24）：計畫經使用者確認，分支 `m6`（從 `ui-refine` 開，含尚未進 main 的 D-125～D-134）。偏離與取捨記在 `docs/DECISIONS.md` D-135 起。

## 方向

- 來源一律先查 robots.txt 與條款（規則 12）；Google News RSS 的 robots 禁止 `/rss`，不用。
- 重大訊息用證交所／櫃買 OpenAPI（`t187ap04_L`、`mopsfin_t187ap04_O`），不爬 MOPS。
- LLM 免費優先、可隨時增加：服務清單在資料表，全部走 OpenAI 相容的 chat completions（Google AI Studio、Groq、OpenRouter、NVIDIA NIM），用既有的 `httpx`，不加依賴。金鑰只在 `.env`。
- 只送公開內容（新聞、公告、貼文）給 LLM，不送持股。
- 通知優先順序：LINE → Telegram → Email（LINE、Telegram 申請好之前先用 Email）。
- 只存標題、摘要、連結與 LLM 結果，不存全文；社群貼文內文只在處理時使用。

## 任務

### T1 Schema
- `news_sources`：來源目錄（代碼、名稱、`kind`＝adapter、網址或範本、是否逐檔、啟用、間隔、關鍵字、是否送 LLM、最後抓取與錯誤）。RSS 可在 /admin 新增，其他 `kind` 需要 adapter。
- `news_items`：新聞、公告、社群貼文共用一張（`channel`＝news／announcement／social），自然鍵（來源、外部編號），標題、短摘要、發布時間（UTC）、`meta`（推噓數、作者多空、公告條款）、`duplicate_of`（同事件合併），LLM 結果（摘要、情緒 −1～1、事件類型、重要度 1～5、題材、服務與模型、狀態）。
- `news_item_stocks`：關聯（直接、產業、題材）與權重。
- `stock_aliases`：個股別名（關聯用）。
- `slang_terms`：台股與鄉民用語詞典（附初始詞條）。
- `llm_providers`（附四家初始設定）與 `llm_usage`（每服務每日請求、token、費用）。
- `sentiment_daily`：每檔每交易日每範圍（news、ptt、cmoney_forum、all）的篇數、平均情緒、多空與推噓。
- `alerts.kind` 加 `announcement`、`news_sentiment`、`social_buzz`；`alerts.channels` 記錄送出的通道；`job_requests` 加 `sync_news`。

### T2 Provider
新的資料種類 `news`：介面 `NewsProvider`（`fetch_news(source)`／`parse_news(raw)`），實作 `twse`／`tpex` 重大訊息、`rss`、`cnyes`、`cmoney_notes`、`ptt`、`cmoney_forum`。經 `ProviderRouter` 存 RawStore。社群貼文的內文只在 RawStore（30 天後由任務刪除，D-138）。

### T3 關聯與去重（`engine/news.py`，純函式＋測試）
網址正規化、代號與名稱／別名比對、產業與題材關聯、標題字元 bigram 相似度合併同事件（同股 48 小時內）。

### T4 LLM
`common/llm.py`：`LLMRouter` 依優先序挑服務（免費優先、付費要開啟且受每日費用上限），429 或額度用完就冷卻換下一家；輸出用 pydantic 驗證，失敗重試或換服務。漏斗：持股、自選、重大訊息、社群（已有作者多空標記的不送）優先；同事件只送一次；每日上限。社群的提示詞附詞典。

### T5 任務
- `sync_news`：一輪抓所有到期的來源、關聯、去重、LLM、警示；`poll_news` 在 07:00～23:00 循環（`make etl-news`，Windows 排程）。
- `aggregate_sentiment`：收盤後彙整 `sentiment_daily`（`etl-daily` 也會跑）；清 30 天前的社群原始檔。

### T6 通知與警示
- `LineNotifier`（Messaging API push，查當月用量）、`TelegramNotifier`（Bot API），`NOTIFIER=line,telegram,email` 依序；依嚴重度分派：critical＝全部通道；warning＝第一個可用的推播通道；LINE 接近額度時 warning 改走下一個通道。
- 警示：持股或自選的重大訊息（critical，同日同股合併）、新聞情緒極端（warning）、社群熱度突增（info，只在站內）。

### T7 網站
`/news` 頁（全部、持股自選、重大訊息、社群），個股頁「新聞」分頁（新聞、社群、每日情緒圖），首頁加「重大訊息與新聞」區塊；摘要標示「AI 摘要」與來源模型。

### T8 `/admin`
新聞來源（RSS 新增與試抓、啟用、間隔、關鍵字）、LLM 服務（新增、排序、開關、額度與用量）、用語詞典、個股別名、警示門檻（取代「警示規則」佔位）。全部寫 `audit_log`。

### T9 收尾
`/status` 涵蓋列、README、CLAUDE.md、PLAN、DECISIONS。

## 範圍外
Dcard、財經 M 平方、文章全文、向量嵌入、新聞歷史回填（情緒從上線日開始累積）、情緒條件的篩選與回測（M7）。
